# SGMU Test Helper 👩‍⚕️💊

Desktop-приложение для подготовки студентов-медиков к тестированию в СГМУ.
Создано для автоматизации процесса подготовки и самопроверки, заменяя неудобные бумажные методички и онлайн-формы.

## 💡 История создания
Проект родился из реальной потребности: существующие инструменты для подготовки были неудобными или платными. Я разработал это решение, чтобы помочь студентам СГМУ (включая мою вторую половинку и её группу) готовиться к экзаменам быстрее и продуктивнее.

## 🛠 Функционал
*   **Режим тренировки:** Прохождение тестов по выбранным темам без таймера.
*   **Режим экзамена:** Симуляция реального экзамена с ограничением времени.
*   **Работа над ошибками:** После теста приложение показывает неверные ответы и правильные варианты.
*   **Импорт вопросов:** Легкая загрузка новых баз вопросов из текстовых файлов.

## 💻 Технический стек
*   **Платформа:** WPF .NET
*   **Язык:** C#
*   **Архитектура:** MVVM 
*   **Хранение данных:** JSON

## 🚀 Как пользоваться
1. Клонируйте репозиторий.
2. Загрузите файл с базой вопросов (пример базы лежит в папке `Data`).
3. Выберите режим и начните тестирование.
